# Task 5: Ensure Fair Distribution Algorithm

## Description
Implement an algorithm that distributes participants as evenly as possible across teams, handling remainders appropriately (e.g., 23 people, 5 teams = 5,5,5,4,4).

## Acceptance Criteria
- Teams receive as even a number of participants as possible
- Remainder participants are distributed fairly
- Algorithm works for any number of teams and participants

## Deliverable
A fair distribution algorithm, testable by running drafts with uneven numbers of participants and teams.
