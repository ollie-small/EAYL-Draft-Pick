# Task 6: Create Draft Phase UI

## Description
Design and implement the user interface for the draft phase. The UI should show team assignments, current round, team turn, and remaining participants. Include a "Next Pick" control to advance the draft.

## Acceptance Criteria
- Visual draft board displays team assignments
- Progress indicators for round and team turn
- "Next Pick" button/control advances the draft
- Remaining participants are updated in real time

## Deliverable
A functional draft phase UI, testable by running a draft and observing the UI updates.
