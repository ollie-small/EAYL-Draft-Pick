# Task 8: Implement In-Memory State Management

## Description
Manage all application data using JavaScript variables in memory. Data should reset when the page is refreshed or closed.

## Acceptance Criteria
- All state is managed in memory (no persistence)
- Data resets on page refresh or close
- State management supports all app features

## Deliverable
In-memory state management logic, testable by using the app and refreshing the page to confirm data resets.
