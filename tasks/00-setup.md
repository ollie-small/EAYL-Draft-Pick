# Task 0: Project Setup and Boilerplate

## Description
Set up the initial project structure for the Draft Pick application. Organize your files and folders for clarity and maintainability. Create the main HTML file and prepare separate files for CSS and JavaScript.

## Acceptance Criteria
- A `draft/` directory exists (if not already present)
- An `index.html` file is created in the `draft/` directory
- Separate files for CSS (e.g., `style.css`) and JavaScript (e.g., `app.js`) are created in the `draft/` directory
- The `index.html` file includes basic HTML5 boilerplate and links to the CSS and JS files
- The project structure matches the updated specification
- The app can be opened in a browser and displays a placeholder message

## Deliverable
A working project structure in the `draft/` directory, including `index.html`, `style.css`, and `app.js`, testable by opening `index.html` in a browser and seeing a placeholder message.
