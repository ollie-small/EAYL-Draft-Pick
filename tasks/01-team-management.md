# Task 1: Implement Team Management UI and Logic

## Description
Create the user interface and logic for managing teams. Users must be able to add, edit, and delete teams before the draft starts. The team list should update in real time. A minimum of 2 teams is required to proceed to the draft phase.

## Acceptance Criteria
- Users can add new teams with custom names
- Users can edit and delete teams
- Team list updates immediately on changes
- Minimum 2 teams required before draft can start
- All changes are reflected in the UI

## Deliverable
A working UI and logic for team management, testable by adding, editing, and deleting teams.
