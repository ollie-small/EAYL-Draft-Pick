# Task 4: Build Automated Draft Process

## Description
Implement the logic to randomly assign participants to teams in a round-based draft. The process should ensure all participants are assigned and the draft can be started from the UI.

## Acceptance Criteria
- "Start Draft" button triggers the draft process
- Participants are assigned to teams randomly in rounds
- No participant is left unassigned
- Draft can be started only after setup validation passes

## Deliverable
A working draft process, testable by running a draft and verifying all participants are assigned to teams.
