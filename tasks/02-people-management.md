# Task 2: Implement People Management UI and Logic

## Description
Create the user interface and logic for managing participants. Users must be able to add, edit, and delete people before the draft starts. The participant list should update in real time. A minimum of 2 participants is required to proceed to the draft phase.

## Acceptance Criteria
- Users can add new participants
- Users can edit and delete participants
- Participant list updates immediately on changes
- Minimum 2 participants required before draft can start
- All changes are reflected in the UI

## Deliverable
A working UI and logic for people management, testable by adding, editing, and deleting participants.
