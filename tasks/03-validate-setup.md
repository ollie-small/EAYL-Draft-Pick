# Task 3: Validate Setup Before Draft

## Description
Implement validation logic to ensure the draft cannot start unless there are at least 2 teams and 2 participants. Provide clear validation messages to guide the user.

## Acceptance Criteria
- Draft cannot start unless minimum requirements are met
- User receives clear error/validation messages
- UI prevents progression to draft phase if requirements are not met

## Deliverable
Validation logic and UI feedback, testable by attempting to start the draft with insufficient teams or participants.
